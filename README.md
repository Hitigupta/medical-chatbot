# AI-Powered Medical Information Chatbot

An AI-powered medical information chatbot that uses Retrieval-Augmented Generation (RAG) to retrieve relevant information from a medical knowledge base and generate context-grounded responses to user queries.

## Overview

This project explores how large language models and semantic search can be combined to make medical information easier to access through a conversational web interface.

## Features

- **Retrieval-Augmented Generation:** Retrieves relevant medical context before generating a response.
- **Semantic Search:** Uses text embeddings and Pinecone vector search to find relevant information.
- **LLM-Powered Responses:** Integrates a hosted language model through an API.
- **Web Interface:** Provides a conversational interface backed by a Flask application.
- **Modular Backend:** Separates application logic, retrieval, and prompt construction where applicable.

## Tech Stack

- **Backend:** Python, Flask
- **LLM Orchestration:** LangChain
- **Vector Database:** Pinecone
- **Embeddings:** Sentence Transformers (`all-MiniLM-L6-v2`)
- **Language Model API:** Groq
- **Frontend:** HTML, CSS, JavaScript

## Architecture

1. The user submits a medical information query through the web interface.
2. The Flask backend processes the request.
3. The query is used to retrieve relevant document chunks from Pinecone through semantic search.
4. The retrieved context is passed to the language model.
5. The generated response is returned to the frontend.

## Setup and Installation

1. Clone the repository.
2. Create and activate a Python virtual environment.
3. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Configure the required API keys and settings using environment variables.
5. Start the Flask application:

   ```bash
   python app.py
   ```

6. Open the local URL printed by Flask in your browser.

Refer to the configuration requirements before running the application.
